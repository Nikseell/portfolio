# Portfolio

A personal portfolio site for showcasing web and game development work. Built with React, TypeScript, and Vite.

## Tech Stack

- **React 19** + **TypeScript** — UI and type safety
- **Vite** — build tool and dev server
- **Tailwind CSS 4** — styling
- **Motion** — animations
- **Lenis** — smooth scrolling
- **Lucide React** — icons

## Structure

- `src/sections` — page sections (Hero, About, Experience, Work, Breaker, Footer)
- `src/components` — reusable UI components (Cursor, Reveal, KineticGrid, WorkCard)
- `src/layout` — layout and navigation
- `src/lib` — animation and scroll utilities
- `src/data` / `src/types` — content and type definitions

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run preview` — preview production build
